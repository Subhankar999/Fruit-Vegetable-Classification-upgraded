# 🍎 Fruit & Vegetable Classification using CNN

A deep learning-based image classification application that identifies fruits and vegetables from images using a custom **Convolutional Neural Network (CNN)** built with **PyTorch**.

The project provides an interactive **Streamlit web application** where users can upload an image, capture an image using their camera, or classify multiple images at once.

The application uses a custom CNN model trained to classify images into **88 different fruit and vegetable classes**.

Users can:

- Upload an image for classification
- Capture an image using their camera
- Get the predicted fruit or vegetable
- View the prediction confidence
- View the top-K predictions
- Classify multiple images simultaneously
- Download batch prediction results as a CSV file
- View prediction history
- Clear prediction history
- Change the application theme

The application supports image formats including **JPG, JPEG, PNG, and WEBP**.
